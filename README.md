# 🌐 Surayya Issah — Personal Portfolio Website

A modern and responsive personal portfolio website created as the **final project for an HTML5 & CSS3 Web Design course** by **Surayya Issah**.
The project demonstrates the practical application of HTML5 and CSS3 concepts to create a professional portfolio website that works across desktop, tablet, and mobile devices.

## 🔗 Live Website

**Portfolio:**
lovelynaj.github.io/Surayya_Issah/

## 📖 Project Overview

This portfolio website was designed to showcase Surayya Issah's creativity, web design skills, photography projects, services, and contact information through a clean and modern interface.

The website was developed from scratch using **HTML5 and CSS3**, with responsive design techniques to ensure a good experience on different screen sizes.

## ✨ Features

* Responsive navigation bar
* Mobile hamburger menu
* Hero/Introduction section
* About Me section
* Personal statistics
* Portfolio gallery
* Services section
* Contact information
* Contact form
* Call-to-action section
* Social media links
* Responsive footer
* CSS hover effects and transitions
* Responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **CSS Flexbox**
* **CSS Grid**
* **CSS Media Queries**
* **Font Awesome**
* **Google Fonts**
* **Web3Forms**

## 📱 Responsive Design

The website has been designed to adapt to different screen sizes, including:

* 🖥️ Desktop computers
* 💻 Laptops
* 📱 Mobile phones
* 📲 Tablets

The navigation automatically changes to a **hamburger menu on smaller screens** to provide a better mobile browsing experience.
